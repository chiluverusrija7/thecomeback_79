# Developer Portfolio — Srija Ch

A modern, high-impact personal developer portfolio built for **Srija Ch** (CSE B.Tech Student at KL University), showcasing engineering projects, core CS focus areas, categorized skill toolkits, certified credentials, hackathons, and interactive technical case studies.

---

## 🚀 Tech Stack

- **Frontend Core**: React 19, JavaScript (JSX), Vite
- **Styling**: Tailwind CSS v4, Glassmorphism, CSS Custom Tokens
- **Icons**: Lucide React & Inline Vector Graphics
- **Routing**: React Router DOM (`HashRouter`)
- **Visualizations**: 2D HTML5 Canvas Graph Physics & Interactive Algorithm Viewers

---

## ✨ Features & Architecture

- **6 Active Client Routes**:
  - `/` — 10-Part Editorial Homepage (Hero with Status Pill, Complexity Ticker, About, Skills, Featured Projects, Certifications, Achievements, Education, Final CTA, Footer)
  - `/projects` — Projects Showcase with category tabs, search bar, dynamic counts, and empty state reset
  - `/projects/:projectId` — Editorial Case Study Page with data-driven architecture flow diagrams, algorithms, and empirical metrics
  - `/certifications` — Credentials & verification page with search and category filtering
  - `/achievements` — Hackathon showcase cards and an interactive vertical milestone timeline
  - `/contact` — Client-side validated contact form, mailto dispatch trigger, and social links
- **Interactive Visuals**:
  - BFS node graph simulator with animated edge data packets
  - Desktop cursor ambient lighting aura (`AmbientCursor.jsx`)
  - Mouse-tracking spotlight cards (`GlassCard.jsx`)
- **Global Command Palette**: `Ctrl+K` keyboard shortcut quick navigation overlay

## 🛠️ Setup & Installation

Clone the repository and install dependencies:

```bash
# Clone repository
git clone https://github.com/chiluverusrija7/thecomeback_79.git
cd thecomeback_79

# Install packages
npm install
```

---

## 💻 Local Development

Run the Vite local dev server:

```bash
npm run dev
```

Open `http://localhost:5173/` in your browser.

---

## 📦 Build for Production

Compile the production bundle:

```bash
npm run build
```

The optimized output will be generated in the `dist/` directory.
